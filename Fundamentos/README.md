## 🎯 Objetivo

O objetivo deste repositório é consolidar os fundamentos da linguagem Java por meio de teoria, exercícios e projetos práticos, criando uma base sólida para o desenvolvimento de aplicações backend com Spring Boot e para entrevistas técnicas.
