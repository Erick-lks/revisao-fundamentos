# Java Fundamentos — Exercícios e Revisões

Repositório dedicado à revisão e prática dos principais fundamentos da linguagem Java.

O objetivo deste projeto é consolidar conhecimentos essenciais por meio de exercícios práticos, exemplos de código e pequenos desafios, criando uma base sólida para o desenvolvimento de aplicações com Java.

## Conteúdos estudados

- Lógica de programação
- Variáveis e tipos de dados
- Operadores aritméticos, relacionais e lógicos
- Estruturas condicionais (`if`, `else`, `switch`)
- Estruturas de repetição (`for`, `while`, `do while`)
- Arrays e matrizes
- Métodos e parâmetros
- Programação Orientada a Objetos
  - Classes e objetos
  - Encapsulamento
  - Herança
  - Polimorfismo
  - Abstração

- Coleções
  - `List`
  - `Set`
  - `Map`
  - `Queue`

- Tratamento de exceções
  - `try`
  - `catch`
  - `finally`
  - `throw`
  - `throws`

- Manipulação de strings
- Exercícios de lógica e desafios práticos

## Tecnologias utilizadas

- Java
- JDK 17 ou superior
- IDE recomendada: IntelliJ IDEA, Eclipse ou VS Code

## Como executar os exercícios

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/java-fundamentos-exercicios.git
```

2. Acesse a pasta do projeto:

```bash
cd java-fundamentos-exercicios
```

3. Abra o projeto na sua IDE.

4. Execute a classe que contém o método `main`.

Este repositório faz parte da minha jornada de estudos em desenvolvimento Java. A proposta é evoluir continuamente nos fundamentos da linguagem e registrar exercícios que reforcem conceitos importantes para projetos futuros com Java e Spring Boot.
